# Services Reference

Every client call goes through the **API Gateway** (`http://localhost:8010`, Swagger at `/docs`). Ports below are *host:container*. Unless noted, tenant-scoped routes need `Authorization: Bearer <token>`.

## API Gateway

**Port:** 8010:8000 · **Source:** `services/api-gateway/`

### Endpoints the gateway owns

| Method | Path | Description |
|---|---|---|
| `POST` | `/evaluate` | **Async** underwriting — find-or-creates customer/policy, publishes `ProposalSubmittedEvent`, returns `202 { event_id, proposal_id, status }`. The `risk_result_worker` persists the result. |
| `POST` | `/evaluate/stream` | Synchronous underwriting over SSE — one event per LangGraph node, then persists the `RiskAssessment` |
| `GET` | `/assessments` · `/assessments/stats` · `/assessments/{id}` | Risk assessment list, SQL-aggregated stats, detail |
| `POST` | `/quote` | Instant deterministic premium quote from the tenant's `InsurancePlan` rates (no LLM, no Kafka) |
| `GET` / `PATCH` | `/quotes` · `/quotes/{id}` | Stored quotations (incl. those generated by the quote worker) |
| `POST` | `/suggest-plan` | LLM plan recommendation (forwards to Risk Engine) |
| `POST` | `/chat/stream` · `/chat/resume` · `/chat/title` · `/chat/execute-tool` | AI copilot (proxied to Chat Agent with the caller's auth) |
| `GET` | `/events/stream` | SSE stream of live case events for the caller's tenant (15 s heartbeat) |
| `POST` | `/summarize/stream` | SSE proxy to the Text Summarizer |
| `GET` | `/health` | Health check |

`/evaluate` and `/evaluate/stream` require `X-Tenant-Id`. When the body carries a `case_id`, the [requirements/evidence gate](/data-flow#requirementsevidence-gate-runs-before-either-evaluate-path-below) runs first.

## Tenant Service

**Port:** 8011:8001 · **Source:** `services/tenant-service/` · **Swagger:** `http://localhost:8011/docs`

## Risk Engine

**Port:** 8012:8002 · **Source:** `services/risk-engine/`

Runs the LangGraph underwriting workflow (`workflow.py`); plan bands in `underwriting_rules.py`; fraud graph writes in `graph_writer.py`; Kafka consumer in `consumer.py`. Does **not** write to PostgreSQL.

| Method | Path | Description |
|---|---|---|
| `POST` | `/evaluate` | Run the workflow → full evaluation result |
| `POST` | `/evaluate/stream` | SSE — one event per node, then the final result |
| `POST` | `/suggest-plan` | LLM plan recommendation for a customer |
| `GET` | `/health` | Health check |

`insurance_type` is one of `TERM_LIFE`, `WHOLE_LIFE`, `ENDOWMENT`, `CHILD_EDUCATION_MARRIAGE` (the last also needs `policy.dependent_dob`). See [Data Flow](/data-flow) for node and decision-rule details and [Fraud Layer](/fraud-layer) for the graph.

| Variable | Default | Description |
|---|---|---|
| `MEMGRAPH_URI` | `bolt://memgraph:7687` | Fraud graph (`MEMGRAPH_USERNAME` / `MEMGRAPH_PASSWORD` optional) |
| `KAFKA_BOOTSTRAP_SERVERS` | `kafka:9092` | Consumer + producer |
| `TENANT_SERVICE_URL` | `http://tenant-service:8001` | LLM config lookup |

## OCR Engine

**Port:** 8014:8004 · **Source:** `services/ocr-engine/`

| Method | Path | Description |
|---|---|---|
| `POST` | `/extract` | Upload a PDF/image → extracted text + token usage |
| `POST` | `/extract/stream` | Same, streamed as SSE |
| `POST` | `/extract-customer` | Read a form/ID and return customer fields (used for quick lead onboarding) |
| `POST` | `/extract-structured` | Text-only structured extraction (no vision call) |
| `POST` | `/extract-from-path` | Process a file from the shared `/data` volume (`./shared/documents`) |
| `GET` | `/health` | Health check |

Formats: PDF, PNG, JPG, JPEG, TIFF, BMP. Text-heavy documents are transcribed (tables as Markdown); visual/medical images get a `Visual Analysis` section.
